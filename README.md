# Project Name: Comprehensive User Activity Insights


## Description:
This project contains SQL scripts for analyzing user activity within an application. It includes reports for:

- Quarterly user activity, showing the first day of each quarter, total unique users, and total sessions.

- Identification of inactive users, listing those who have not logged in over the past five months, along with their last login timestamp and account status.

The queries are designed to support management in tracking engagement trends, monitoring inactive users, and making data-driven decisions.

## Technologies: MySQL

## Usage:
Clone the repository and execute the SQL scripts on your user and login tables to generate the reports.
